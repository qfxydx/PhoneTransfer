# PhoneTransfer v1.0.2 · macOS 文件选择器热修复

本次版本针对 macOS 上「电脑向手机传送文件 → 选择文件…」可能导致应用长时间无响应的问题进行修复。继承 v1.0.1 的安全与稳定性增强，不修改手机端文件操作逻辑。

## 修复内容

- 修复取消 macOS 原生文件选择器后，应用可能又打开第二个 Qt 文件选择窗口的问题。
- 调整文件选择器辅助进程的信号连接及快速退出处理，避免程序因错过退出通知而继续等待。
- 打开文件选择窗口时不再隐藏 PhoneTransfer 主界面。
- 不再在点击「选择文件」时同步编译 Swift 辅助组件，避免构建过程阻塞界面。
- 如果选择器组件不可用，清楚提示错误；仍可通过拖拽文件方式添加传输项目。

## 验证情况

- 53 项无设备自动化测试通过，其中 9 项为新增加的文件选择器回归测试。
- 既有 Quick View / MainWindow UI 回归测试通过。
- Android 15 模拟器端到端小文件传输和文件安全回归结论仍适用；本次热修复不涉及新的 Android 设备操作测试。
- 自动化测试不能代替所有 macOS 交互环境下的人工操作验证，欢迎反馈兼容性问题。
