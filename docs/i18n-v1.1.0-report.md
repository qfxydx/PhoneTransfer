## Earlier focused follow-up QA — 2026-11-03

The existing local changes were retained. This follow-up changes only the log presentation/classification code, the two source-spec bundle versions, and this report; it adds `phonetransfer/log_kinds.py` and `tests/test_i18n_log_kinds.py`. No translations, README, existing tests, release scripts, or ADB/worker implementation were edited during this follow-up.

Fixed the regression where localized messages without a leading icon became `info`:

- Known UI outcomes now carry an explicit kind when the result reaches the log: raw exceptions/failures are `error`, successful results/connections are `success`, cancellation/disconnection/debugging hints are `warning`, and detection is `device`. The existing worker signals and cancellation sentinels retain their contracts.
- Legacy `Signal(str)` messages use `log_kinds.SOURCE_KINDS`, keyed by the existing stable catalog source IDs. The active catalog's **complete rendered template** is matched, with placeholders treated as dynamic values. There are no target-language keyword lists or translated substring guesses. Unknown raw diagnostics remain `info` unless the receiving outcome supplies a kind; canonical ADB prefixes/summaries and neutral status symbols have their own format rules.
- `MainWindow` stores parsed entries alongside its existing full string history. Expansion/collapse reuses those entries, preserving explicit kinds even for arbitrary stderr; the text-only `LogDetailList.sync_lines` compatibility path is also covered. The root entry point's exported parser helper remains available.
- Every log retains its original localized text, filename, path and raw stderr. ADB success summaries retain the **entire** original line in their detail. No 96-character truncation. Labels use plain text so `<...>` and `&` in diagnostics are displayed literally. Device/transfer glyphs are now neutral `▣` / `↔`.
- `PhoneTransfer.spec` now sets both `CFBundleVersion` and `CFBundleShortVersionString` to **1.1.0**. The existing six locale JSON catalogs and six `qtbase_*.qm` resources remain explicitly bundled.

## Implementation

- Six complete UTF-8 catalogs: `zh-CN`, `en`, `ja`, `ko`, `de`, `es`; **464 entries per language**. One central `tr` function handles lookup and named formatting. No per-widget language branches.
- Default: macOS preferred UI languages through `QLocale.system().uiLanguages()`, first supported language; region/script variants match the language family. Chinese variants map to Simplified Chinese; no supported match falls back to English.
- Upper-right globe-only language menu: System / Auto plus six native language names, keyboard accessible and persistent through explicitly scoped `QSettings`. **Changes apply after quitting and reopening**; the localized confirmation explains this and leaves active operations running.
- Coverage: main window, both transfer directions, presets/categories, browsing/context menus, selection helper failures, logs/status/progress, transfer errors and cancellation, wireless pairing and port-5555 warnings, clipboard/text/URLs/notes, scrcpy guidance, APK errors/source warnings, conflict/delete/rename/new-folder dialogs, preview title/errors, sponsorship, toasts and notifications. Technical tokens and runtime paths/names/diagnostics stay intact.
- Qt-owned buttons use a central `QTranslator` adapter; other Qt controls use Qt's qtbase catalogs. Unknown Qt messages return a null translation so shortcut parsing and built-in fallback continue working.
- PyInstaller manifest explicitly packages the JSON directory and six installed Qt qtbase `.qm` resources. Resource lookup is relative to the module, independent of the working directory; extracted frozen-style layout is tested.
- Base window stays `742×680` for all six locales. Maximum-width restriction removed; cards allow growth. Local destination presets use two columns; text/scrcpy actions stack vertically. Warnings, summaries, status labels and toasts wrap. Long indeterminate-progress captions are no longer forced into 42 px. Shortcuts remain unchanged.
- Logs retain full localized diagnostics rather than parsing Chinese prefixes or truncating messages at 96 characters. The remote-operation UI callbacks now use the existing log/toast method signatures; no remote operation behavior changed.
- README is English by default, with a complete Chinese companion and reciprocal links. Both preserve the four original screenshot paths and the direct v1.0.2 DMG link, and explain ADB prerequisites, optional scrcpy, unsigned/unnotarized status, debugging security, and the reusable temporary clip JAR. The issue template accepts English/Chinese and includes language/translation fields, retaining the existing `bug` label.
