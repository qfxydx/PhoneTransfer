# PhoneTransfer v1.1.0 — Six Languages / 六语言国际化

## English

PhoneTransfer v1.1.0 adds six UI languages and improves international usability while retaining the v1.0.2 file chooser fixes and existing ADB-based file transfer functionality.

- **6 UI languages:** Simplified Chinese, English, Japanese, Korean, German, and Spanish. The first supported macOS preferred language is selected automatically.
- **Discreet globe icon:** choose System / Auto or a language from the icon-only top-right menu. A changed selection takes effect after restarting the app.
- **Localized warnings and diagnostics:** improved clarity for transfer, connectivity, APK and clipboard messages, preserving the original data, paths, and error details.
- **English and Chinese READMEs**, refreshed screenshots, an Issue template, and regression tests.
- **Validation:** 86/86 automated tests passed; the packaged six-language diagnostic app and normal GUI launch were checked.

**Requirements:** macOS 11+; ADB/Android platform-tools must be installed separately. Enable and authorize USB debugging on a trusted Mac. scrcpy is optional; **MTP is not supported**. Clipboard support depends on Android versions and ROMs.

**Security and compatibility:** The DMG is ad-hoc signed, **not** Apple Developer ID signed or notarized. macOS may require approval via Privacy & Security. Do not disable system-wide security. Real-device transfer and compatibility across Android ROMs have not been comprehensively retested for this release. Please report issues on GitHub with sanitized logs.

## 中文

v1.1.0 在保持 v1.0.2 文件选择器修复及现有 ADB 文件传输能力的基础上，重点完善国际化与使用体验。

- **六语言界面：**简体中文、英语、日语、韩语、德语、西班牙语；默认跟随 macOS 首选语言。
- **地球图标语言菜单：**顶部右侧只显示小地球图标，不展示当前语言名称；点击选择“系统 / 自动”或六种语言，重启应用后生效。
- **日志与安全提示本地化：**覆盖传输、连接、APK 和剪贴板等消息，保留原始路径、文件名及错误细节。
- **GitHub 中英文说明**、更新的界面截图、Issue 模板及回归测试。
- **验证：**86/86 项自动化测试通过，六语冻结包诊断和正常图形界面启动检查通过。

**使用前提：**macOS 11 及以上；需单独安装 ADB/Android platform-tools，在可信 Mac 上授权 USB 调试。scrcpy 为可选依赖；**不支持 MTP**。剪贴板效果取决于 Android 版本和 ROM。

**安全与兼容性：**安装包仅采用 ad-hoc 签名，**没有 Apple Developer ID 正式签名，也未经公证**。macOS 可能要求在“隐私与安全性”中批准打开，请勿关闭全局安全保护。此次未对所有 Android ROM 进行真机传输回归，发现问题欢迎在 GitHub Issues 提交复现步骤及脱敏日志。
